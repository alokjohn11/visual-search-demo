Visual Search Demo – Privacy Policy

Last updated: 5 September 2026

Visual Search Demo is a development and testing application for WhatsApp-based visual product search.

Information processed

When an authorized test user sends an image through WhatsApp, the image is temporarily processed to generate visually similar product suggestions. Customer image bytes are not intentionally stored permanently.

Technical logs

The application may retain limited technical information for testing, reliability, and troubleshooting purposes. This may include timestamps, pseudonymized user identifiers, request identifiers, returned product identifiers, processing latency, and error information.

Access tokens, application secrets, full phone numbers, raw webhook payloads, and customer image files are not intentionally stored in application logs.

Purpose

This application is currently intended for controlled development and testing and is not a public customer-facing service.
